# dummy-mcp-server-rust

Dummy MCP server built with [rmcp](https://github.com/modelcontextprotocol/rust-sdk)
3.x, targeting the [2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/)
protocol revision. See the [repo root README](../README.md) for the full set
of fixtures.

## Run locally

```bash
cargo run
```

## Build

```bash
cargo build --release
```
